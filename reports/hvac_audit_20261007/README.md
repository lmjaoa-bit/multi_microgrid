# HVAC 冷热切换核验（2026-10-07）

最明确的证据是：确定性策略仍有冷热换向，并且当前 Critic 对部分 HVAC 局部动作的累计收益排序与环境回放相反。无死区为微调提供了执行通道；目标平滑噪声的物理尺度明显大于微调尺度。但现有诊断不能把四个因素都确认为首因，也不能确定它们的因果排序。

## 证据范围

- 主模型：正在训练的 `matd3_mlp_dueling_critic_h24_q_guided`，固定第 1900 回合选出的 `best_model.pt`；快照 SHA-256 为 `b2e53e4f846189ae482210325d3219243f9ac7b1a57901abae8b25677a8c4f11`。
- 回放：2018 年测试集全部 55 个自然日，每日 24 步；Actor 动作噪声为零。分别开启、关闭预测噪声，使用相同日期及种子。
- 当前环境使用 `exact_zoh` 热离散化、`soft_comfort` 舒适度惩罚，无 HVAC 终端温度要求。诊断没有更新模型、改配置或启动训练，也没有写入源运行。
- 反事实抽样：每月各选一个换向状态、小功率状态、大功率状态和晚间状态，共 48 个状态、621 条候选比较。每条比较只改变当前 HVAC 动作，之后由固定参数的确定性策略闭环运行到日末。这是分层诊断样本，不是总体误判率估计。
- 旧调度图对应 `matd3_dueling_feasible_actor` 的 2026-10-05 运行，已从清理备份读取原始轨迹。该旧模型使用 legacy Euler，不能与当前模型直接做算法优劣比较。

## 核验结果

| 假设 | 观测证据 | 能支持的结论 |
|---|---|---|
| 连续动作无死区造成微调/换向 | 开关预测噪声时都没有接近零功率的停机步；1 kW 以下微调分别为 103、93 小时。动作映射和目标都没有显式死区、换向滞回或换向成本。 | 存在允许微调的结构条件；不能仅据此证明所有冷热切换不合理。 |
| Critic 排序错误 | 95 次精确 ±1 kW 比较中，51 次累计奖励差绝对值超过 0.001（对应广义成本差 0.1）。Q1 错号 16 次，Q2 错号 22 次，min(Q1,Q2) 错号 17 次；双 Q 同时错号 7 次。 | 对所测状态及确定性闭环收益，动作排序误差已经实测；Actor 使用 Q1 的梯度，双 Q 不能完全消除该问题。 |
| TD3 平滑扰动过大 | 标准差 0.2 对应 7 kW，截断 0.5 对应 17.5 kW。18 个目标动作绝对值低于 0.1 的抽样状态中，512 次 HVAC 单通道扰动的冷热跨界率中位数为 42.8%。48 状态中 39 个平均目标 Q 下降。 | 噪声确实大幅跨越冷热两侧；只做了固定模型敏感性测量，没有噪声参数重训练对照，不能认定它导致所学策略抖动。 |
| 团队奖励稀释 HVAC 信号 | 精确 ±1 kW 比较的实际奖励差绝对值中位数为 0.001237；Q1 差值误差绝对值中位数为 0.003359。团队奖励是负的总成本除以 100，没有除以智能体数。 | 局部动作收益常小于当前 Critic 差值误差；不能把这一事实单独归因于团队奖励汇总，也不能用统一放大奖励解决相对比例。 |

关闭预测和动作噪声后，55 天中 44 天仍出现超过 1 kW 的制热和制冷，同日相邻小时直接冷热换向累计 109 次。开启预测噪声时对应为 44 天、122 次。这里的计数只定义切换现象，不把所有切换都判为浪费。

48 个抽样状态中，15 个状态改为当前小时停机能改善累计奖励，且随后每个小时的 HVAC 舒适度违约没有恶化。例如 2018-07-29 01:00：原动作制冷 5.689 kW，改为停机后累计奖励提高 0.08120（广义成本下降 8.120），舒适度不恶化；Q1 却预测奖励差为 -0.04149。此结论只涵盖 HVAC 舒适度，未将其他设备服务逐项声明为无恶化。

## 死区反事实对照

对固定 Actor 的输出外加死区过滤器，其他机制保持原样；预测噪声开启。该实验没有重新训练策略。

| 外加死区 | 相邻小时冷热换向（超过 1 kW） | 日均广义成本变化 | 日均舒适度违约变化（°C·h） | 舒适度恶化天数 |
|---|---:|---:|---:|---:|
| 无 | 122 | 0 | 0 | 0 |
| 1 kW | 122 | -0.422 | +0.00080 | 4 / 55 |
| 3 kW | 54 | -2.480 | +0.02836 | 13 / 55 |

1 kW 死区消除了小功率执行，却没有减少超过 1 kW 的直接换向。3 kW 死区能明显减少换向，但牺牲了部分日期的舒适度。因此不能把“加死区”直接视为无代价修复，更不能由固定策略过滤实验推出重新训练后的效果。

## 验证与复现

已核对日期小时唯一性、每个日期 24 步、数值有限性、源文件和固定模型哈希。反事实参考分支与保存轨迹的后缀累计奖励最大差为 `7.11e-15`；收益差与成本分解恒等式最大差为 `2.35e-14`。

在仓库根目录使用当前 Python 环境：

```powershell
$env:MKL_THREADING_LAYER = 'SEQUENTIAL'
$env:OMP_NUM_THREADS = '1'
python reports/hvac_audit_20261007/audit.py baseline
python reports/hvac_audit_20261007/audit.py probes
python reports/hvac_audit_20261007/audit.py deadband
python reports/hvac_audit_20261007/summarize.py
```

`baseline` 在已有快照时复用快照，不读取训练过程中更新的 best_model。原始证据包括 `hourly_forecast_*.csv`、`counterfactual_probes.csv`、`deadband_daily.csv`，以及 `source_manifest.json`、`audit_summary.json`。`audit.ipynb` 提供计算核对视图。

当前证据足以支持继续检查动作价值辨识与停机/换向设计，但尚无不同噪声、奖励结构或动作结构的重训练消融，因此“四者均为首要原因”的论断仍需收窄。

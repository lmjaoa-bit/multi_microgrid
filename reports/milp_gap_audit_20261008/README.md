# MILP 差距复核：2026-10-08

本报告针对当前 Dueling 算法第 4600 轮最优模型的 55 天正式测试。搁置 Critic 修复，审查更大的调度改进空间。未修改算法、环境、奖励、配置或正式结果，未启动训练。

## 结论

单独模块的优先顺序为储能日内调度、HVAC 全日用能安排、EV 充电安排、磨机生产安排。完整数字在 `review_summary.json`，固定曲线 MILP 与实际环境回放均覆盖同一组 55 天。

| 仅重排该模块，其他实际功率曲线固定 | MILP 日均降低广义成本 | 原环境回放日均降低广义成本 |
|---|---:|---:|
| 储能 | 52.83 | 52.83 |
| HVAC | 46.71 | 46.71 |
| EV | 35.87 | 29.76 |
| 磨机 | 24.67 | 24.67 |
| 三种 DR 同时重排 | 98.28 | 88.73 |

这些是全信息优化的诊断机会，不是重新训练后的收益预测。各单独模块之间有交互，不能相加。三种 DR 一起优化涉及三个设备，不能与单个模块按同等实施范围比较。

## 总成本差距

正式测试的日均广义成本为 1201.26，保存的 Reward V2 MILP 参考为 1049.38，差距 151.88。账目分解如下：购电 111.08、负荷峰值 24.56、碳成本 6.81、舒适 5.43、弃电 4.91；电池损耗则比 MILP 少 0.91。磨机未服务、EV 离站欠充、未供电的平均成本均接近零。

峰值指标是团队实际负荷峰值，不含储能充电功率。因此储能优化的收益主要来自购电时序，而非直接降低此峰值指标。

## 主要机会的含义

储能单独优化可降低购电成本约 51.95/天，同时电池损耗增加约 1.46/天。它使用更多电池循环：三台电池合计日均充电由 668.36 kWh 增至约 751.17 kWh，放电由 481.25 增至约 544.86 kWh。优化模型的购网充电加权电价约由 0.457 降至 0.409；放电时段对应的加权电价约由 0.666 升至 0.700。后者是时段电价暴露，不是出售电能的收入。

HVAC 单独优化降低购电约 25.50、峰值约 7.69、弃电约 5.67、舒适惩罚约 5.11/天。最优用电量反而由约 262.16 增至 327.03 kWh/天，说明机会涉及时段转移、热状态和富余可再生能源利用，不能概括成减少空调用电。全天优化与此前单次 ±1 kW 的 Critic 检查尺度不同。

EV 在 MILP 中可以按车群分配功率；环境仅接受总功率，并通过内部紧迫度规则分配各车群。部分 MILP 曲线无法被当前接口完全执行，EV 单独优化的最大逐时功率偏差约 18.29 kW，因此应以原环境回放的 29.76/天评价当前接口的机会，而不能直接采用 MILP 的 35.87。

## 能量分配比较的校正

正式结果中的 `oracle_replay_profit_gap` 当前实现直接比较策略和会计 MILP 的轨迹，并没有把同一套 MILP 动作放回环境执行。它不能用于量化清算规则造成的损失。

本次单独固定所有实际 ESS/DR 功率曲线，仅允许 MILP 改变能量分配。其团队广义成本与策略账目几乎一致，最大差值约 0.00013。当前这组场景中，大量微网间流向差异并未形成显著的团队成本差距。无需把更改 P2P 分配规则作为首要收益来源。

## 方法与验证

1. 重算所有保存的 MILP 轨迹成本，核对基荷、可再生能源和正式日报。九项账目差值加总误差最大约 1.9e-12。
2. 对每个日期求解七组诊断 MILP：全部控制固定、仅储能自由、仅磨机自由、仅 HVAC 自由、仅 EV 自由、全部 DR 自由、全部自由。共 385 个模型。通过运行时附加固定约束完成，不改共享优化器文件。
3. 对八组曲线逐步调用原环境，包括正式策略原始动作，共 440 次日回放。55 天原始动作回放成本均与正式成本相符。
4. 固定曲线带来的数值退化通过关闭预处理重试；个别模型用至多 1e-6 功率单位的固定约束带。求解器可行性容差为 1e-5，最大固定变量误差小于 1e-5；非负变量上的微小负值按零校正。成本与求解下界的最大差值约 0.123，远小于各模块几十元的日均机会。完整数值记录在 `fixed_dispatch_results.csv`，不会修改物理约束或正式结果。
5. 重算单模块的收益与原环境执行误差，并复核源文件哈希。

MILP 使用完整未来信息，策略仅使用其观测与有噪声预测。数字衡量有条件的调度机会，不证明具体网络或训练机制是根因，也不保证在线算法能够追回全部机会。广义成本包含非现金惩罚，与会计利润不同。本报告不包含算法修复，未运行算法变更所需的训练冒烟流程。
